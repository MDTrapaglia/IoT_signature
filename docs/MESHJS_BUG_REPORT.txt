================================================================================
BUG REPORT: MeshJS v1.9.0-beta.90 - Cannot convert undefined to a BigInt
================================================================================

Date: 2026-01-09
Reporter: ESP32 IoT Certification System Project
Version: @meshsdk/core v1.9.0-beta.90
Network: Cardano Preprod Testnet

================================================================================
SUMMARY
================================================================================

MeshJS v1.9.0-beta.90 fails when building transactions that SPEND from Plutus V3
script addresses. The error occurs during the .complete() phase with:

  "Error: Evaluate redeemers failed: Error serializing outputs:
   Cannot convert undefined to a BigInt"

This bug ONLY affects spending operations - creating outputs to Plutus V3
scripts works correctly.

================================================================================
ERROR DETAILS
================================================================================

Full Error Stack Trace:
-----------------------
Error: Evaluate redeemers failed: Error serializing outputs: Cannot convert undefined to a BigInt
    at Object.computeMinimumCost (node_modules/@meshsdk/transaction/dist/index.js:4107:19)
    at async computeMinimumCost (node_modules/@meshsdk/transaction/dist/index.js:1387:19)
    at async computeChangeAndAdjustForFee (node_modules/@cardano-sdk/input-selection/src/RoundRobinRandomImprove/change.ts:447:26)
    at async _MeshTxBuilder.selectUtxos (node_modules/@meshsdk/transaction/dist/index.js:4144:12)
    at async _MeshTxBuilder.complete (node_modules/@meshsdk/transaction/dist/index.js:4069:25)

Error Location:
--------------
The error occurs during the transaction building phase when calling .complete()
on a MeshTxBuilder that includes:
- .spendingPlutusScriptV3()
- Input from a Plutus V3 script address
- Script code attachment
- Redeemer
- Collateral

Error Phase:
-----------
The error happens specifically during:
1. computeMinimumCost() - trying to calculate execution units
2. Evaluate redeemers - evaluating the Plutus script
3. Serializing outputs - converting transaction to CBOR

Root Cause:
----------
During the CBOR serialization process, an internal field is undefined and
MeshJS attempts to convert it to BigInt, which is illegal in JavaScript:
  BigInt(undefined) -> TypeError

================================================================================
ANALYSIS
================================================================================

Bug Location:
------------
The bug is in MeshJS's internal transaction building code, specifically in:
- @meshsdk/transaction/dist/index.js:4107 (computeMinimumCost)
- @cardano-sdk/input-selection (computeChangeAndAdjustForFee)

The error occurs when MeshJS tries to:
1. Evaluate the Plutus script redeemer
2. Calculate execution units (memory + CPU steps)
3. Serialize the transaction to CBOR
4. An internal field is undefined
5. Code tries: BigInt(undefined) -> Error

Why Create Works but Spend Fails:
---------------------------------
- CREATE: Only writes to blockchain, doesn't evaluate scripts
- SPEND: Must execute the Plutus validator, which triggers the buggy code path

This is a bug in MeshJS's Plutus V3 evaluation/serialization code, NOT in
user data or configuration.
